Ben Miller ZigTensor

The library has to compile

30 March 2025

ZigTensor is supposed to be a deep learning library you can read. Not a Python binding with a C++ basement. Tensors, ops, autodiff, CUDA, all of it owned in one place, with Zig’s explicit allocators and error unions instead of a framework’s hidden graph. That is the bet. Day one is not a tensor. Day one is a build.

The first commits throw out whatever scaffolding was in the way, add a contrived unit test, and make compilation depend on that test passing. An error set is imported so it can grow. Types get tests before they get bodies. The semi-colon convention is established like it matters, because in Zig it does. By the end of the 30th the repo knows how to fail in public.
