CPU and GPU are not the same init

2 April 2025

If the tensor is going to live on two machines, it cannot pretend they start the same way. CPU and GPU initialization split. Leak tests stop hiding behind defer so a forgotten free actually fails the build. New errors cover reading the buffer as a slice or a pointer, because “just give me the bytes” is how a library starts lying.

The session is messy on purpose. refAllDecls is a hack to get something compiling. A second monitor is not architecture. What survives is the split: host memory and device memory are different contracts, and the Tensor has to say so at init rather than at the first kernel launch.
