Fill on the way in

9 April 2025

zeros and ones are not convenience helpers in a from-scratch library. They are the first time a Tensor is born with a defined buffer instead of whatever the allocator left behind. Fill-on-init lands with a test, then merges as PR #10.

The GPU version of this is still an open issue. The CPU path is the one that exists. After this, creating a tensor with a value is part of the type, not a loop the caller writes every time.
