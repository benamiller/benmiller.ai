Gone generic

3 April 2025

The Tensor goes generic. That is the maintenance bet: one implementation, dtype as a parameter, callers stop copy-pasting f32 special cases. Once the type can be many things, element-wise add has to mean something. In-place add lands with tests, then a second path that should fail when the dtypes do not match.

This is the first operation that looks like a library instead of a struct. Not GEMM, not a network. Two tensors, same shape, add. The error set for tensor-tensor work starts here. A few WIP tests get reverted the same afternoon. The shape of the API is the point, not the arithmetic.
