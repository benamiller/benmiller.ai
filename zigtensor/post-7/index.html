Nine months. Then the build.

22 January 2026

Nine months. The first commit of the year is build.zig and the message is the status: Revival begins... Still broken. Zig has moved. addStaticLibrary is addLibrary with a root_module. Tests get a module too. Later the same evening: main should build, Zig doesn’t like spaces, LSP formatting.

The tensor from April is still the tensor. Generic, initCpu, fill, in-place add. No kernel in the tree. No autodiff. The project is alive again, which is not the same as a library you can train with. The silence had a cost: the language shipped, the build file did not.
