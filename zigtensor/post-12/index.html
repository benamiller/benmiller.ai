MNIST as a check, not a framework

24 May 2026

The 23rd adds a tiny HTTP get and an MNIST path in Zig. The 24th checks in the raw MNIST files and a Python benchmark that runs the same idea in PyTorch. The point is not to depend on PyTorch. The point is a number you can argue with: does our tensor math match theirs on a dataset everyone already believes.

Sigmoid appears as an empty-ish operations file in the same breath as the fetch. The north star is parity, not a zoo of layers. If the library cannot learn MNIST in a way you can compare, the rest of the README is fiction.
